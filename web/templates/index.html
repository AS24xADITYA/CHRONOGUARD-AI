How ChronoGuard Works

Three-phase flow from raw network metadata to explainable threat forecast

01

Flow Sequence Aggregation

Ingests standard CICFlowMeter records, cleans numerical anomalies, and aggregates flows into sliding time windows (W=10) measuring volume, timing, and TCP flag dynamics.

02

LSTM Sequence Forecasting

The 2-layer recurrent network models state transitions, forecasting infiltration probability across K=3 future horizons and categorizing the emerging attack stage.

03

Self-Attention Explainability

A self-attention pooling layer highlights exactly which historical time windows and anomalous traffic features (e.g. SYN bursts, IAT collapses) drove the forecast.
